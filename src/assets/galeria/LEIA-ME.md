# Galeria de criativos avulsos

Coloque aqui imagens soltas (que não fazem parte de um case) para aparecerem na galeria da página **/cases/**.

- Formatos: `.jpg`, `.png`, `.webp` ou `.avif`. Até ~2000 px no lado maior é suficiente.
- O nome do arquivo vira a descrição da imagem (para leitores de tela). Ex.: `post-black-friday-kyoto.jpg` → "post black friday kyoto".
- Pelo GitHub, sem instalar nada: abra esta pasta no site do GitHub → **Add file** → **Upload files** → arraste as imagens → **Commit changes**. O site é publicado de novo sozinho.

Para trocar as peças de um case, edite `src/data/cases.ts` e as imagens em `src/assets/criativos/<case>/`.
